# 화면 제작 기준

[사용자 맥락](context.md)과 릴스 01 제작 기록 (`../production/reel-01/storyboard.md`; 로컬 자료·배포 제외)에 이미 기록된 방향을 모았다. 첫 제작본의 구체적인 스타일을 모든 영상의 승인된 규칙으로 확대하지 않는다.

## 확인된 방향

- 사업·제품·실제 일화가 먼저 보이고, 투자 분석의 깊이와 재미가 함께 전달돼야 한다.
- 2026-10-02 제작 기록의 사용자 방향은 세련되고 고급스러운 3D, 부드러운 모션, 멋진 전환이다.
- 실제 장면과 설명에 필요한 화면을 내레이션과 함께 설계한다. 문서와 숫자를 나열하는 화면만으로 구성하지 않는다.

## 첫 제작본에서 사용한 선택

릴스 01은 검은 스튜디오, 샴페인 골드 차량, 흰빛, 사물로 표현한 역할 분담을 사용했다. 레퍼런스에서 빛으로 제품을 드러내는 순서, 절제된 글자, 넓은 여백, 공간 이동으로 설명하는 방식을 가져왔다. 상세 목록과 장면별 모션은 storyboard.md (`../production/reel-01/storyboard.md`; 로컬 자료·배포 제외)에 있다.

이는 첫 제작본의 선택이다. 색감·재질·편집 속도·인물 등장 여부와 최종 포맷은 공통 확정 사항이 아니다.

## 사실과 화면의 관계

- 설명용 가상 차량·시설과 실제 현장 자료를 구분한다.
- 한국·일본 협력 사례에 테슬라의 성과라는 인상을 주는 표현을 붙이지 않는다.
- 다시 그린 신청 카드와 실제 사이트 화면을 구분하고, 모집을 계약 완료처럼 표현하지 않는다.
- 이미지·모델을 재사용할 때 공통 자산 출처 (`../assets/CREDITS.md`; 로컬 자료·배포 제외)와 해당 편의 자료 출처를 확인한다.

## 검수

주요 장면과 전환에서 차량·자막·라벨이 읽히는지, 설명용 표기가 보이는지 확인한다. 실제 음성도 들어 발화·자막·장면의 대응을 확인한다. 레퍼런스의 화면을 본 것과 소리를 들은 것을 구분해 기록한다.
