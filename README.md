# Reels Automation

**투자용 릴스 제작에 최적화된 에이전트 하네스**다. 주식·ETF·금융시장의 실제 사건 조사부터 투자 판단, 대본, 화면 설계, 제작과 검수까지 이어지는 작업 지침을 담고 있다. 에이전트 설정과 스킬은 `.agents/skills/` 하나에서 관리한다.

## 시작하기

1. 이 저장소를 Claude에서 작업 폴더로 열고 [AGENTS.md](AGENTS.md)를 읽어 달라고 한다.
2. **Claude와 대화하면서 어떤 릴스를 만들지 물어보고 함께 정한다.** 예: “이 하네스의 지침을 읽고, 어떤 투자 릴스를 만들면 좋을지 추천해 줘. 내 관심사를 물어보면서 주제와 방향을 같이 정하자.” 관심 있는 회사·ETF·시장 이슈가 있다면 함께 알려 준다.
3. Claude가 [사용자의 의도](docs/intent.md)와 해당 단계의 스킬을 참고해 후보를 제안하면, 원하는 제목을 고르고 대본·화면 설계·제작으로 이어 간다. 한 단계만 필요하면 “이 소재를 조사까지만 해 줘”처럼 요청한다.

제목 선택 → 대본 승인 → 화면 방향 선택의 관문은 작업 지도를 따른다. 사용자가 특정 단계만 요청하면 거기서 멈춘다.

Remotion 번들의 중첩 문서와 예제 코드는 상대 참조를 유지하기 위해 포함한다. 번들 자체의 아이콘과 지도 예제는 제작 영상의 에셋이 아니다.

## 로컬 작업 자료와 실행 환경

이 저장소는 **지침과 지식의 하네스**다. 기존 `production/`, 공용 `assets/`, 렌더·음성·모델·사진·원본 영상, 인증정보, 예약 실행기, 실행 로그 및 기존 Git 이력은 포함하지 않는다. 제작물은 `.gitignore`로도 제외한다.

새 작업을 시작할 때 로컬에 `production/feed.md`, `production/pitches/`, 편별 `production/<reel-id>/`를 만든다. 피드가 없으면 신규 피드로 시작하고, 문서에 나오는 과거 편의 결과를 현재 설치의 제작물이나 검증 결과로 간주하지 않는다. 에셋을 준비하면 로컬 `assets/README.md`와 `assets/CREDITS.md`에 출처를 기록한다.

스킬에 등장하는 기존 자막 부품·ORCA 안내 화면·음성 생성 및 게시 스크립트는 이 저장소에 들어 있지 않다. 제작 전에 사용자가 보유한 자료를 연결하거나 해당 단계에서 준비해야 한다. 문서의 “설치됨”, “시험함”, 계정·구독 상태는 원래 작업 환경의 과거 기록이다. 현재 환경에서는 다시 확인한다. 원본과 실행기 없이 이 저장소만으로 기존 영상을 재렌더하거나 자동 게시할 수는 없다.

Blender, FFmpeg, Node.js와 Remotion, 음성 API, 금융 데이터, Drive 및 게시 계정은 필요한 단계에서 별도로 설정한다. `docs/context.md`의 과거 자동 실행 허용을 새로운 계정의 게시 허가로 해석하지 않는다. 인증정보는 로컬 환경변수나 제외된 `.env`로 관리한다.

큰 파일 경로는 문서에서 `$REELS_DATA_DIR`로 표시한다. 사용 가능한 저장장치의 절대 경로로 지정하고 필요한 하위 폴더를 만든다. 특정 컴퓨터의 홈 디렉터리를 전제로 하지 않는다.

과거 기록에서 배포 대상 밖의 파일을 가리키던 링크는 경로 표기로 남겼다. 해당 원자료를 읽지 않았다면 검증했다고 보고하지 않는다. 문서에 인용한 조사 수치와 도구 상태는 기록된 날짜의 자료다.

## 저장소 관리

하네스 수정만 커밋한다. 기존 작업 폴더의 Git 이력은 가져오지 않았으며, 이 저장소의 루트가 Git 경계다. 에이전트별 별도 설정 폴더나 오케스트레이터 설치 없이 `.agents`의 절차를 읽어 작업한다.
