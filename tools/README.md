# 도구 색인

사용자가 주거나 작업자가 찾은 도구를 한 줄에 하나씩 적는다. 받는 순서와 판정은 [받기 스킬](../.agents/skills/reels-intake/SKILL.md)에 있다. 이미 쓰고 있는 도구(Blender, Remotion, ElevenLabs, Kling, rclone)의 쓰는 법은 각 스킬에 있고 여기에 옮기지 않는다.

- **상태**: 받음 → 살펴봄 → 시험함 → 실전에 씀 / 보류 / 탈락(까닭)
