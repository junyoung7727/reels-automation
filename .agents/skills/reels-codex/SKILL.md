# Codex 릴스 제작

프로젝트 루트는 이 파일의 실제 위치에서 `../../..`이다. [AGENTS.md](../../../AGENTS.md), [의도](../../../docs/intent.md)가 공통 원본이다. 스킬은 `.agents/skills/` 한 곳에서 관리한다. 이 스킬은 Codex가 공통 단계의 결과를 실제 영상으로 연결하는 실행 기준이다.

## 2. 판단하는 법

깊이는 문장의 길이나 전문용어 수가 아니다. **사건 → 경쟁과 수급 → 판매가격·원가·이익 → 현재 주가에 반영된 기대 → 매수 조건**이 연결되는가로 본다. 차트는 매매 시점과 손실 관리의 근거이며 기술 성공이나 기업가치의 증거가 아니다. 금융 전문가의 실제 검토를 받지 않았다면 받았다고 쓰지 않는다.

## 3. 순서와 결과

| 설계 | [화면 설계](../reels-design/SKILL.md), [주요 개선사항](../reels-key-improvements/SKILL.md) | 줄마다 실제 재료, 그림이 설명할 인과, 움직임의 시작·끝을 적는다. 실제 자료를 확보한 뒤 시안을 만든다 |

이번처럼 사용자가 자동 실행과 재제작을 명시했으면 이미 맡긴 제목·대본·화면 선택을 다시 승인받느라 멈추지 않는다. 선택은 작업자의 것으로 기록한다. 다 만든 편은 검수와 드라이브 업로드 뒤 인스타그램에 바로 올린다([게시 스킬](../reels-publish/SKILL.md)의 D6, 사용자 2026-10-15). 별도 CLI나 오케스트레이터는 만들지 않는다.

## 4. 실제 실행 기준

### 과거 편과 직접적인 후킹

관련 편의 결론을 사실처럼 계승하지 말고 당시 근거와 현재 자료를 다시 비교한다. “중국 제품과 무엇이 다른가”, “먼저 발표한 쪽은 누구인가”, “지난 매수 의견은 아직 유효한가”처럼 지금 시청자가 자연히 물을 것을 이번 이야기 안에서 해소한다. 이전 편을 안 봐도 이해되도록 필요한 맥락만 한 줄로 준다.

첫 질문과 첫머리는 [후킹 스킬](../reels-hook/SKILL.md)을 따른다(영상 유형마다 다르다. 회사와 주가를 직접 묻고, 물체 비유를 먼저 해석해야 하는 질문은 고친다).

### 투자 의견의 인과와 매매 시점

[판단 스킬](../reels-verdict/SKILL.md)의 4.2(살 계획과 분석 기록)와 4.4(반박 검수)를 따른다. 이 절에 있던 기록의 꼴(기준일과 시장, 사업 인과, 가격의 뜻, 사는 조건, 반증과 손익, 다음 확인 시점)은 2026-10-16에 그쪽으로 옮겼다.

### 실물과 모션으로 설명하기

영상은 현장과 행동, 사진은 인물과 제품, 모션은 비교·시간차·수급·손익 구조를 맡긴다. 종류별 할당량이나 컷 수는 만들지 않는다. 같은 사진을 확대만 해 놓고 적극적인 활용이라고 하지 않는다. 실물의 일부가 그래픽의 기준점으로 이어지거나, 실제 가격 선 위에 진입·무효화·회수 구간이 차례로 생기는 식으로 말의 인과를 움직임으로 만든다.

차트의 **기준일·핵심 가격·조건 구분은 오독 방지 정보**이므로 필요한 곳에 크게 남긴다. 출처는 공용 마지막 장면과 출처 문서에 모은다. 미래 경로를 이미 일어난 가격처럼 잇지 않는다. 표식·범위로 조건을 보인다.

## 5. 내기 전에 확인

- 과거 편에서 자연히 생기는 질문을 찾아 답했고 기존 의견이 바뀌면 이유를 말했는가.
- 첫 질문을 물체나 공정 지식 없이 이해할 수 있는가. 실제 회사와 투자 문제가 들리는가.
- 사업의 변화부터 매수 시점까지 “왜”가 이어지는가. 가격·조건·근거·철회 기준이 구체적인가.
- 실제 차트의 날짜와 수치에서 조건을 재현할 수 있는가. 전망과 조건을 실현된 사실처럼 그리지 않았는가.
- 영상·사진·모션이 각각 이야기를 설명하는 구간을 프레임으로 짚을 수 있는가.
- 근거가 틀리지 않다는 검사와 투자 의견·편집이 좋다는 평가를 혼동하지 않았는가.

## 6. 보고와 기록

`brief.md`에 위 항목이 나온 대본 줄과 실제 프레임/시각을 적는다. 최종 보고는 완성 영상 링크, 바뀐 핵심, 실제 확인 범위로 짧게 한다. 문서만 고치고 영상에 반영했다고 하지 않는다. 이전 판은 보존한다.

## 7. 파일

공통 근거는 `docs/intent.md`, 사용자 원문은 `docs/context.md`. 편별 분석·대본·스토리보드·검수는 해당 `production/<reel-id>/`에 둔다. 이 스킬의 원본은 `.agents/skills/reels-codex/` 하나이며 Codex의 검색 경로에서는 링크로 연결할 수 있다.

## 8. 해석과 교체 기록

2026-10-15: 사용자가 정한 것은 이전 편 연결, 차트 시점과 매수 근거, 전문가가 납득할 인과, 직접적인 후킹, 자료와 모션의 적극적인 활용이다. 특정 지표·분할 비중·손익비·컷 수는 사용자가 정하지 않았다. 위 기록 형식은 이를 검토 가능하게 만드는 작업자의 방법이다. 기존 스킬의 “첫 문장 숫자 하나”는 강제 조건에서 예시로 바꾸고, 차트 기준일까지 지우게 하던 날짜 금지는 오독 방지 예외를 둔다.
