## 프레임에서 본 것

- 참고 영상의 첫 3초 (`ref-hooks-first3s.png`; 로컬 자료·배포 제외)와 우리의 첫 3초 (`ours-hooks-first3s.png`; 로컬 자료·배포 제외), 전체 훑어보기 (`ref-overview.png`; 로컬 자료·배포 제외).
- brivael (`ref-brivael.png`; 로컬 자료·배포 제외): 크림색 종이, 판화로 통일한 인물 초상을 액자 카드에, 세리프 글자, 붉은 도장, 판 번호, 말에 맞춰 단어가 칠해지는 자막 상자.
- shneural (`ref-shneural.png`; 로컬 자료·배포 제외): 화면을 채우는 큰 글자, 색 면 전체가 바뀜, 크롬 3D가 화면의 3분의 1, 작은 라벨과 눈금.
- donaldjewkes (`ref-donaldjewkes.png`; 로컬 자료·배포 제외): 네 가지 색과 망점 질감으로 통일한 그림, 글자가 그림 안에 들어가 있음.
- stephanlivera의 1.5초 (`ref-stephanlivera-1.5s.png`; 로컬 자료·배포 제외): 번짐, 잔상, 눈금, 시간 표시 같은 작은 디테일이 프레임마다 있음.
- rexan_wong의 작업 순서 (`ref-rexan-workflow.png`; 로컬 자료·배포 제외): 참고 영상 고르기 → 색·글꼴·성격 형용사 정하기 → 박자마다 스토리보드(배치, 정확한 글자, 무엇이 움직이는지, 들어오고 나가는 전환) → 단계마다 확인받고 멈춤 → 공통 디자인 값으로 제작, 처음부터 끝까지 이어지는 요소 하나.
