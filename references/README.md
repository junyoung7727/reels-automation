# 레퍼런스 색인

사용자가 주거나 작업자가 찾은 영상·이미지 레퍼런스를 한 줄에 하나씩 적는다. 받는 순서와 판정은 [받기 스킬](../.agents/skills/reels-intake/SKILL.md), 고르는 법은 [화면 설계 스킬](../.agents/skills/reels-design/SKILL.md)에 있다.

- 원본 영상은 `$REELS_DATA_DIR/reels-build/refs/<묶음>/`에 두고, 여기에는 뜯어본 그림과 판정만 둔다.
- **종류**: 첫 3초 / 그림 세계 / 글자 / 인물 / 3D / 움직임 / 소리 / 구성
- **상태**: 받음 → 뜯어봄 → 규칙이 됨 / 참고만 / 탈락
- "가져올 것"은 우리 화면에 넣을 효과와 수법이다. 그 영상의 형식을 통째로 따르라는 뜻이 아니다(사용자, 10-08: "그러한 3d 효과를 우리 스타일에 맞게"). "가져올 것"과 판정은 작업자의 해석이다. 사용자의 말이 있으면 그 칸에 그대로 적는다. 작업자는 프레임을 뽑아 봤고 재생과 소리는 확인하지 못했다.
